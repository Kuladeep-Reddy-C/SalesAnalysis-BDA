## 4. Which ML model should you choose?

I recommend starting with these two approaches.

| Approach                | Purpose                                                                                    |
| ----------------------- | ------------------------------------------------------------------------------------------ |
| Historical baseline     | Predict sales using recent historical sales, such as the previous week's corresponding day |
| Random Forest Regressor | Learn nonlinear relationships among past sales, prices, and calendar features              |

Evaluate both on the same chronological test period. Do not randomly split time-series records, because future data could leak into training.

Use these metrics:

- MAE: Average absolute prediction error, in sales units.
- RMSE: Penalizes large prediction errors more heavily.
- WAPE: Total absolute error relative to total actual sales.
- Execution time: Time required to preprocess and train.
- Scalability: How processing time changes with the amount of data or available Spark resources.

Don't assume Random Forest will outperform the baseline. Your conclusion should follow the actual results.
